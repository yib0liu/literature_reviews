# AMP: Adversarial Motion Priors for Stylized Physics-Based Character Control
## 对抗式运动先验：用于风格化基于物理的角色控制

**作者**: Xue Bin Peng, Ze Ma, Pieter Abbeel, Sergey Levine, Angjoo Kanazawa  
**单位**: UC Berkeley / Shanghai Jiao Tong University  
**发表**: ACM Transactions on Graphics (SIGGRAPH 2021)  
**arXiv**: 2104.02180  

---

## 摘要

为物理模拟角色合成优雅、栩栩如生的行为，一直是计算机动画领域的一项基本挑战。利用运动追踪的数据驱动方法是生成各种行为高保真运动的一类主要技术。然而，这些基于追踪的方法的有效性往往取决于精心设计的目标函数；当应用于大型、多样化的运动数据集时，它们还需要大量额外的机制来在给定场景中为角色选择合适的追踪运动。

在本工作中，我们提出一种基于对抗模仿学习的完全自动化方法，旨在消除手动设计模仿目标和运动选择机制的需求。角色应执行的高级任务目标可通过相对简单的奖励函数来指定；而行为的低级风格，则可通过一个非结构化的运动片段数据集来指定，无需任何显式的片段选择或排序。这些运动片段被用来训练一个对抗式运动先验（Adversarial Motion Prior），它为通过强化学习（RL）训练角色提供风格奖励。对抗性强化学习过程能够自动选择要执行的运动，并从数据集中动态地进行插值与泛化。

我们的系统能生成高质量的运动，其效果可与最先进的基于追踪的技术相媲美，同时能轻松适应大型非结构化运动片段数据集。不同技能的组合能够自动从运动先验中涌现，无需高级运动规划器或对运动片段进行任务特定的标注。我们在一系列复杂的模拟角色和富有挑战性的运动控制任务上验证了我们框架的有效性。

## 1. 引言

基于物理的角色动画长期以来面临一个根本性挑战：如何在不大量手动调整奖励函数的情况下，生成自然、逼真的动作。传统的数据驱动方法通常依赖于运动追踪（motion tracking），即通过精心设计的目标函数让角色跟随参考运动数据。这类方法虽然能产生高保真的动作，但存在两个关键局限：

1. **需要手动设计目标函数**：追踪-based 方法的有效性高度依赖于精心设计的目标函数，这需要大量的人工调参和领域知识。
2. **难以处理大型多样化数据集**：当面对大量非结构化的运动片段时，需要额外的复杂机制来选择在特定场景下应该追踪哪个运动片段。

为了解决这些问题，我们提出了**对抗式运动先验**（Adversarial Motion Priors, AMP）。AMP 的核心思想是：**将任务目标与运动风格解耦**。高级任务目标由简单的手动设计奖励函数指定，而低级运动风格则由一个对抗式判别器从非结构化运动数据中自动学习。

### 1.1 核心贡献

- 提出了一种基于对抗模仿学习的框架，消除了手动设计模仿目标和运动选择机制的需求
- 通过对抗式运动先验实现任务与风格的解耦，支持从非结构化运动数据中自动学习风格
- 实现了自动技能组合——不同技能（如行走+出拳）能从运动先验中自然涌现，无需高级运动规划器
- 在多种复杂角色形态（人形、霸王龙、狗）和具有挑战性的运动控制任务上验证了方法的有效性

## 2. 相关工作

### 2.1 基于运动学的方法（Kinematic Methods）

基于运动学的方法从动作库中选择轨迹进行回放。给定一个运动数据集，控制器可以被构建来为特定场景选择一个运动片段进行播放。这类方法的局限性在于：
- 需要对动作库进行标注和组织，成本很高
- 遇到新场景时无法泛化

### 2.2 基于物理的方法（Physics-Based Methods）

#### 2.2.1 传统方法

传统的基于物理的方法通过精心设计的目标函数来控制角色运动。这类方法能确保物理合理性，但需要大量手工调参。

#### 2.2.2 模仿学习方法

DeepMimic（Peng et al., 2018a）是基于追踪的深度学习方法的代表。它通过设计跟踪目标函数让角色模仿参考动作。虽然效果出色，但需要：
- 精心设计的奖励函数
- 策略与参考运动之间的相位同步
- 显式的运动选择和排序机制

#### 2.2.3 生成对抗网络（GAN）

生成对抗网络（GAN）在多个领域取得了成功。在模仿学习中，GAIL（Generative Adversarial Imitation Learning, Ho & Ermon, 2016）将 GAN 的思想引入到强化学习中，通过判别器区分专家轨迹和策略生成的轨迹，并将判别器的输出作为隐式奖励函数。

AMP 借鉴了 GAIL 的思想，但针对只有状态信息（无动作信息）的运动捕捉数据进行了改进。

### 2.3 相关理论基础

#### 2.3.1 最小二乘 GAN（LSGAN）

标准 GAN 使用 sigmoid 交叉熵损失，可能导致梯度消失问题。LSGAN（Mao et al., 2017）使用最小二乘损失替代交叉熵，提供更稳定的训练。

#### 2.3.2 梯度惩罚（Gradient Penalty）

WGAN-GP（Gulrajani et al., 2017）引入了梯度惩罚来稳定对抗网络的训练。梯度惩罚鼓励判别器具有平滑的梯度，防止模式崩溃。

## 3. 方法

### 3.1 整体框架

AMP 框架通过对抗性训练范式引入了一种双重奖励系统，将任务规范与风格规范分离。系统的核心组件包括：

1. **目标条件策略**（Goal-Conditioned Policy）：负责完成高级任务
2. **对抗式运动先验**（Adversarial Motion Prior）：通过判别器学习运动风格

![图2: AMP框架将目标条件策略与对抗性运动先验相结合。判别器学习区分参考运动和模拟行为，提供指导自然运动的风格奖励。](figure2.png)

### 3.2 奖励函数设计

系统的总奖励函数由两部分线性组合而成：

$$r_t = w^G r^G(s_t, s_{t+1}, a_t, g) + w^S r^S(s_t, s_{t+1})$$

其中：
- $r^G$ 是**任务奖励**（task reward），由人工简单设计，指定角色应完成的高级任务
- $r^S$ 是**风格奖励**（style reward），从对抗式运动先验中学习得到
- $w^G$ 和 $w^S$ 是权重系数，在所有任务中设为 $w^G = 0.5$，$w^S = 0.5$

#### 3.2.1 任务奖励

任务奖励是相对简单的手动设计函数，用于指定角色应完成的高级目标。例如：
- **目标朝向任务**：奖励角色朝目标方向移动
- **目标位置任务**：奖励角色接近目标位置
- **打击任务**：奖励角色在正确的位置和时机出拳

任务奖励的设计不需要考虑动作的风格细节，只需关注任务是否完成。

#### 3.2.2 风格奖励

风格奖励通过对抗式运动先验学习得到。其核心思想是：训练一个判别器来区分参考数据集中的真实运动片段和策略生成的合成运动，然后将判别器的输出转换为风格奖励。

风格奖励的具体形式为：

$$r^S(s_t, s_{t+1}) = \max\left[0, 1 - 0.25(D_\phi(s_t, s_{t+1}) - 1)^2\right]$$

其中 $D_\phi$ 是判别器网络。偏移量、缩放和截断的目的是将学习到的奖励函数限制在 $[0, 1]$ 范围内，这有助于训练的稳定性。

### 3.3 对抗式运动先验设计

#### 3.3.1 判别器架构

运动先验被实现为一个判别器网络 $D_\phi$，它区分参考数据集中的真实运动片段和策略生成的合成运动。一个关键创新是：**判别器在状态转移 $(s_t, s_{t+1})$ 上操作，而非状态-动作对 $(s_t, a_t)$**。这是因为产生运动捕捉数据的原始动作通常是未知的——我们只有运动学数据（关节位置、速度等），而没有产生这些运动的肌肉力或关节扭矩信息。

#### 3.3.2 判别器输入特征

判别器接收经过精心选择的特征，这些特征捕捉与风格相关的运动特性：

| 特征类型 | 描述 |
|---------|------|
| 根部线速度和角速度 | 角色根部在局部坐标系中的运动 |
| 局部关节旋转 | 使用6D法向-切向编码表示 |
| 局部关节速度 | 各关节的角速度 |
| 末端执行器位置 | 在角色局部坐标系中的位置 |

这些特征侧重于跨时间步的动态和姿态变化，同时保持与任务无关。特别地，速度特征对于捕捉翻滚等动态运动至关重要——仅靠静态姿态信息是不够的。

#### 3.3.3 最小二乘 GAN 目标

判别器使用最小二乘 GAN（LSGAN）目标而非标准 sigmoid 交叉熵，这提供了更稳定的训练：

$$\mathcal{L}_D = \mathbb{E}_{(s,s') \sim \mathcal{M}}[(D_\phi(s,s') - 1)^2] + \mathbb{E}_{(s,s') \sim \pi}[(D_\phi(s,s') + 1)^2]$$

其中 $\mathcal{M}$ 表示参考运动数据集，$\pi$ 表示策略生成的轨迹。

采用 LSGAN 的原因是为了解决标准 GAN 训练中常见的梯度消失问题。当判别器过于自信时，sigmoid 交叉熵的梯度会变得非常小，导致策略无法获得有效的学习信号。LSGAN 的二次损失函数避免了这一问题。

### 3.4 训练稳定性

为了确保对抗性训练的稳定性，AMP 采用了以下关键技术：

#### 3.4.1 梯度惩罚（Gradient Penalty）

在判别器损失中加入梯度惩罚项：

$$\mathcal{L}_{total} = \mathcal{L}_D + w^{gp} \cdot \text{GP}(\phi)$$

其中梯度惩罚项 $\text{GP}(\phi)$ 鼓励判别器具有平滑的梯度，防止模式崩溃和训练振荡。消融研究表明，**梯度惩罚是最关键的组件**——移除它会导致训练高度不稳定并显著降低性能。

#### 3.4.2 参考状态初始化（Reference State Initialization）

在每个训练回合开始时，角色的初始状态不是从零开始，而是从参考数据集中随机采样的状态开始。这一策略有以下好处：
- 让策略从一开始就接触到高质量的参考运动
- 加速探索过程
- 提高训练稳定性

#### 3.4.3 回放缓冲区（Replay Buffer）

维护一个策略生成轨迹的历史记录缓冲区，用于判别器训练。这可以防止判别器过拟合到当前策略的最新行为，确保判别器始终看到多样化的"假"样本。

### 3.5 策略训练

策略使用近端策略优化（PPO）算法进行训练。策略网络接收当前状态和目标信息，输出动作分布的参数。训练过程中，策略最大化以下目标的期望回报：

$$J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}\left[\sum_{t=0}^{T} \gamma^t (r^G_t + r^S_t)\right]$$

根据任务和角色的不同，每个策略的训练需要 1 亿到 3 亿个样本，在 16 个 CPU 核心上大约需要 30 到 140 小时。

## 4. 实验结果

### 4.1 实验设置

#### 4.1.1 角色模型

| 角色 | 自由度 (DoF) | 类型 |
|------|-------------|------|
| 人形角色 (Humanoid) | 34 | 双足 |
| 霸王龙 (T-Rex) | 59 | 双足 |
| 狗 (Dog) | 64 | 四足 |

#### 4.1.2 运动数据集

- 数据来源：CMU 运动捕捉数据库
- 最大数据集包含 56 个片段，来自 8 个不同的演员
- 总计 434 秒的运动数据
- 数据集无需任何标注或组织

#### 4.1.3 评估任务

| 任务 | 描述 |
|------|------|
| Target Heading | 朝指定方向移动 |
| Target Location | 移动到指定位置 |
| Obstacles | 跨越障碍物（跑+跳+翻滚） |
| Stepping Stones | 在石块上跳跃 |
| Dribble | 运球 |
| Strike | 行走并出拳 |

### 4.2 任务性能

下表记录了各任务的归一化任务回报（0 为最低，1 为最高）：

| 角色 | 任务 | 数据集 | 任务回报 |
|------|------|--------|---------|
| Humanoid | Target Heading | Locomotion | 0.90 ± 0.01 |
| Humanoid | Target Heading | Walk | 0.46 ± 0.01 |
| Humanoid | Target Heading | Run | 0.63 ± 0.01 |
| Humanoid | Target Heading | Stealthy | 0.89 ± 0.02 |
| Humanoid | Target Heading | Zombie | 0.94 ± 0.00 |
| Humanoid | Target Location | Locomotion | 0.63 ± 0.01 |
| Humanoid | Target Location | Zombie | 0.50 ± 0.00 |

### 4.3 自动技能组合

AMP 最重要的成就之一是其**自动组合不同技能的能力**，无需显式的运动规划。例如：

- 在"打击"（Strike）任务中，角色学会了走向目标并执行出拳，尽管训练数据仅包含单独的行走和出拳动作
- 这种涌现行为证明了框架能够泛化到参考数据集中未明确出现的动作组合

### 4.4 步态自适应

系统展现出复杂的步态自适应能力：

- 在目标朝向任务中，角色根据目标速度自动在不同步态间切换：
  - 慢速（~1 m/s）→ 步行
  - 中速（~2.5 m/s）→ 慢跑
  - 快速（~4.5 m/s）→ 奔跑
- 还出现了其他类人策略，如转弯时倾斜身体、大幅转向前提前减速
- 这些复杂行为自然地从运动先验中涌现，无需显式的步态调度器

为了验证步态转换确实来自运动先验而非任务目标，研究者用仅包含行走或跑步的有限数据集训练了策略。结果表明：
- 仅用行走数据训练的策略只学会步行，即使在高速目标下也无法切换到跑步
- 仅用跑步数据训练的策略无法匹配低速目标
- 使用多样化数据集训练的运动先验产生了更灵活、更优的策略

### 4.5 多角色性能

该框架不仅限于人形角色：
- **霸王龙**：成功学会了双足 locomotion 和各种风格
- **狗**：展示了自然的四足步态，包括小跑（trotting）、溜蹄（pacing）和疾驰（cantering）

### 4.6 单片段运动模仿

当评估单个运动片段的模仿质量时，AMP 实现了与最先进运动追踪方法相当的质量，同时提供了更大的灵活性：

| 技能 | 持续时间 | AMP误差 | AMP-NoVel误差 | AMP-NoGP误差 |
|------|---------|---------|--------------|-------------|
| Backflip | 1.03s | 0.042 ± 0.001 | 0.058 ± 0.012 | - |
| Spin-Kick | 1.28s | 0.042 ± 0.001 | 0.058 ± 0.012 | - |
| Walk | 1.30s | 0.018 ± 0.005 | 0.030 ± 0.001 | - |
| Zombie | 1.68s | 0.049 ± 0.013 | 0.058 ± 0.014 | - |
| T-Rex Turn | 2.13s | 0.098 ± 0.011 | 0.284 ± 0.023 | - |
| Dog Canter | 0.45s | 0.026 ± 0.002 | 0.034 ± 0.002 | - |
| Dog Trot | 0.52s | 0.019 ± 0.001 | 0.026 ± 0.001 | - |

### 4.7 消融研究

系统性的消融研究验证了关键设计决策的重要性：

1. **梯度惩罚**：移除梯度惩罚导致训练高度不稳定，性能显著下降。这是最关键的组件。
2. **速度特征**：移除判别器输入中的速度特征后，动态运动（如翻滚）的模仿质量大幅下降。静态姿态信息不足以捕捉这些运动。
3. **参考状态初始化**：帮助加速训练并提高稳定性。
4. **回放缓冲区**：防止判别器过拟合。

## 5. 结论与讨论

### 5.1 主要贡献总结

AMP 通过成功地将任务目标与运动风格规范解耦，代表了基于物理的角色动画领域的重大进步。该框架能够从非结构化运动数据中学习，而无需手动设计奖励或明确的运动规划器，解决了该领域长期存在的挑战。

### 5.2 技术意义

1. **自动技能组合**：系统展示了涌现智能——复杂的行为源于训练数据中更简单组件的组合
2. **无需相位同步**：与 DeepMimic 等方法不同，AMP 不需要策略与参考运动之间的显式相位同步
3. **可扩展性**：能轻松处理大型非结构化数据集，最大的数据集包含 56 个片段共 434 秒运动数据

### 5.3 更广泛的影响

- **虚拟角色**：创建能够适应新颖场景同时保持自然运动模式的响应式虚拟角色
- **机器人技术**：从人类演示中学习自然高效的运动模式，可能带来能力更强、能效更高的机器人
- **模块化控制**：任务与风格的解耦使得可以为不同操作环境应用不同的运动先验

### 5.4 局限性

- 训练仍然需要大量的计算资源（30-140 小时）
- 某些复杂任务（如跨越障碍物）的成功率仍有提升空间
- 对抗性训练的稳定性仍需要精心设计（梯度惩罚等技巧必不可少）
